# Provenance et limites

Les descriptions professionnelles sont tirées du CV `Billel_Helali_CV_Agentique_.pdf` fourni par Billel Helali : Doksima en page 1 ; AgentFlow, EchoTrust et PixelLight en page 3. Le PDF n'est pas publié dans ce dépôt. Les chiffres de benchmark du CV ne sont pas repris dans le jeu.

Les liens publics et l'adresse de contact proviennent du README existant, identifié au départ par le blob Git `b39ebcf29a1033f82027f07fb6c43b7079453a7e`. Le contenu existant du profil est conservé en dehors du bloc `agent-lab`.

Les montants 2 400 / 2 700 euros, pièces, avis, brouillons, pannes et crédits sont synthétiques. Les robots PLAN, BUILD et CHECK sont décoratifs ; ils ne représentent pas des modèles exécutés en direct. Les projets professionnels ne sont pas attribués à Claude ou Codex.

Le format aperçu README cliquable → jeu GitHub Pages est inspiré du profil ChetasLua : https://github.com/ChetasLua/ChetasLua. Aucun code, sprite ni visuel de ce jeu n'est copié. Les dessins sont produits par le code de l'Agent Lab et les aperçus sont capturés depuis cette application.

Le code des trois fichiers `src/` et le test `tests/test_lab.py` ont été transférés sans modification depuis le pack préparé dans la conversation. Le workflow de génération et l'intégration du README ont été ajoutés pour la publication sur GitHub.
